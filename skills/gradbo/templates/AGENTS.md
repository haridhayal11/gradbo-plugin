# Gradbo job-search workspace

This folder is the candidate's Gradbo workspace. Their CV, verified facts, reusable answers and every application live here, and nowhere else.

- Use the `gradbo` skill for anything about the job search, and the `humanizer` skill for every piece of prose written for an employer.
- Keep the layout the gradbo skill describes (`profile/`, `answers/`, `applications/`). Read its `references/folder-layout.md` before writing any file. Each application has one folder, `applications/YYYY-MM-DD_employer_role/` (for example `applications/2026-10-23_graphcore_graduate-hardware-engineer-2027/`). Don't create job-search files outside this folder.
- The candidate has authorised you to apply for them: prepare the documents, fill in the form, upload the files and submit, without asking them to review the package or approve the submission, unless they asked you only to prepare or to show them first. Waiting for a final review or approval is never a reason to stop. Stop only to ask for a fact that is missing, for a CAPTCHA or access check, or for a statement only the candidate can make ("this is my own unaided work").
- When the candidate tells you a fact (a demographic answer, a notice period, a reason for wanting a role), write it to `profile/facts.md` straight away, so they are never asked again.
- Never write passwords, one-time codes, cookies or identity documents into this folder.
