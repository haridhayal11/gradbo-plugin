# Consents, declarations and statements

The candidate has asked you to apply, which means accepting what the application cannot go ahead without. Record every box you tick and every statement you accept in the receipt, with its wording.

| What the form shows | Do |
|---|---|
| Privacy policy, terms and conditions, data processing for this application | Accept |
| "The information I have given is accurate and complete" | Accept |
| Any other consent the form **requires** to apply: background checks, references, data retention, a required talent pool | Accept |
| Optional consents: future roles, talent community, sharing with partners | Leave unticked |
| Marketing: newsletters, events, "keep me updated" | Leave unticked |
| A statement of fact about the candidate (right to work, convictions, age, "I have not applied in the last 6 months") | Not a consent: answer only from a verified fact ([questions.md](questions.md) section 3), otherwise ask |
| "This application is my own unaided work" / "I did not use AI" | Don't tick or sign it yourself. Stop and ask the candidate; it is their statement to make |
| An electronic signature (typing a name to sign) | Sign with the candidate's full name from the facts when it signs the accuracy or consent declarations above; record it |

When a required consent is bundled with an optional one in a single box, tick it (the application needs it) and note the bundling in the receipt.
