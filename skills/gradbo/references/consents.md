# Consents, declarations and statements

The candidate has asked you to apply, which means accepting what the application cannot go ahead without. Their standing authorisation for it is in `AUTHORISATION.md` in the Gradbo folder (setup.md, "Standing authorisation"); accept what it covers without asking. Record every box you tick and every statement you accept in the receipt, with its wording.

| What the form shows | Do |
|---|---|
| Privacy policy, terms and conditions, data processing for this application (including consent to process equality-monitoring answers) | Accept |
| "The information I have given is accurate and complete" | Accept |
| Any other consent the form **requires** to apply: background checks, references, data retention, a required talent pool | Accept |
| Optional consents: future roles, talent community, sharing with partners | Leave unticked |
| Marketing: newsletters, events, "keep me updated" | Leave unticked |
| A statement of fact about the candidate (right to work, convictions, age, "I have not applied in the last 6 months") | Not a consent: answer only from a verified fact ([questions.md](questions.md), "Statements of fact"), otherwise ask |
| "This application is my own unaided work" / "I did not use AI" | Don't tick or sign it yourself. Stop and ask the candidate; it is their statement to make |
| An electronic signature (typing a name to sign) | Sign with the candidate's full name from the facts when it signs the accuracy or consent declarations above; record it |

When a required consent is bundled with an optional one in a single box, tick it (the application needs it) and note the bundling in the receipt.

## When your own permission check blocks a tick

Some agents check actions before running them, and may refuse to accept terms "on the candidate's behalf" (Claude Code's auto mode does). Never look for another way to tick it (a different tool, a script, a keyboard trick):

1. **No `AUTHORISATION.md` yet:** ask the candidate once for the standing authorisation (setup.md, "Standing authorisation"); once it is written, try the tick again.
2. **It exists, and the check still refuses** (in Claude Code, the `autoMode.allow` rule is missing on this computer): offer to add the rule (setup.md, step 3 of "Standing authorisation"). For this form, ask the candidate to tick that one box in the open tab and say when it's done, then carry on and submit. Tell them it's the only step left.

Either way, keep going with everything else on the form first, so the tick is the candidate's only step.
